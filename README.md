# Estudos de lógica de programação

Exercícios de lógica de programação desenvolvidos na Alura, usando páginas HTML e JavaScript.

## Organização

- `ex001/ a ex014/`: Funções, IMC, condições, tabuada, médias, jogos, arrays e animações.

## Como estudar e executar

Requisitos: navegador moderno. Para servir os exemplos localmente, Python 3.

```sh
git clone https://github.com/FilipeBandeira/logica-da-programacao.git
cd logica-da-programacao
python3 -m http.server 8000
```

Abra `http://localhost:8000/ex001/func1.html` ou navegue pelas pastas no servidor. Leia o código de cada exemplo, execute-o e compare o comportamento com o assunto estudado.

## Escopo

Os exemplos são independentes e executados no navegador; não há backend ou persistência. Este repositório preserva a trajetória de aprendizado e os créditos dos materiais originais.
